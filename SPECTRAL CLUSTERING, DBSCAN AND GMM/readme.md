# Unsupervised Learning: Spectral Clustering, DBSCAN & GMM

Hands-on implementation and comparison of non-linear and density-based clustering algorithms using `scikit-learn`.

## What's Covered
- **Spectral Clustering:** RBF kernel similarity matrix, Graph Laplacian ($L = D - W$), eigenvalue decomposition, and non-convex clustering (`make_moons`) vs. K-Means.
- **DBSCAN:** Density-based clustering on concentric circles (`make_circles`), $\epsilon$ (epsilon) sensitivity tuning, and $k$-distance elbow plots.
- **Gaussian Mixture Models (GMM):** Soft clustering (`predict_proba`), uncertainty identification, and Expectation-Maximization (EM) log-likelihood convergence on the Iris dataset.

## Tech Stack
- Python, NumPy, Pandas, Matplotlib, Scikit-Learn
